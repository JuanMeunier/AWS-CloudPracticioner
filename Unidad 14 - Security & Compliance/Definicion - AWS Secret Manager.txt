Definición: AWS Secrets Manager

Servicio para almacenar secretos de forma segura.
Permite forzar la rotación automática de secretos cada X días.
Se puede automatizar la generación y rotación con Lambda.
Tiene integración con Amazon RDS para manejar contraseñas de bases de datos.
Los secretos se cifran automáticamente con KMS.
Útil cuando ves un caso de secret management en RDS y rotación, piensa en Secrets Manager.
Es un servicio de pago (aprox. $0.40 por secreto al mes más llamadas API) y suele tener prueba gratuita de 30 días.
